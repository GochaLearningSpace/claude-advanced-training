# エージェント運用 セキュリティチェックリスト

自分が使っている MCP サーバー・skill・エージェント設定に当てはめて使う。

## 秘密情報

- [ ] `.env` 等の秘密情報ファイルが `.gitignore` に入っている
- [ ] コード内にフォールバック用のデフォルト秘密情報(弱い値)が無い
- [ ] 秘密情報未設定時、サイレントに弱い値へフォールバックせず、エラーで停止する

## 権限スコープ

- [ ] `permissions.allow` が「使う操作だけ」に絞られている(`Bash(*)` のような全許可になっていない)
- [ ] エージェントが書き込めるファイルパスが必要範囲に限定されている
- [ ] 外部ネットワークアクセス(WebFetch等)が必要なドメインだけに絞られている

## サプライチェーン(MCPサーバー/skill)

- [ ] 提供元が信頼できる(OSSならメンテ状況・star数、社内製なら管理者が明確)
- [ ] 導入前にコードを読んだ、または読める分量である
- [ ] 実行時に要求するファイル/ネットワークアクセス範囲を把握している

## 運用ルール

- [ ] エージェントの生成物は必ず人がレビューしてから merge する
- [ ] Web取得コンテンツやファイル内容に埋め込まれた指示にエージェントが従っていないか、レビュー時に確認する

## ログ

- [ ] 重要操作(削除・権限変更等)には「誰が・いつ・何を」が追える構造化ログがある
