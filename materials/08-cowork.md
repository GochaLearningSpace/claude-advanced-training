# 8. Claude Cowork(5分・説明+宿題配布)

概念部分(outcomes/webhooks、multi-agent orchestration)は 2. Harness Engineering と 6. Graph Engineering で前振り済み。ここは実務利用の説明と宿題配布に絞る。

## 話す内容

1. **位置づけの整理**(1分)
   「Claude Code はコーディング特化。Claude Cowork は同じ発想をコーディング以外の仕事(ファイル操作、定型業務の自動化)に広げたもの」と一言で定義。

2. **ライセンス確認**(30秒)
   受講者が Cowork を使えるプランかその場で確認。使えない場合は宿題の位置づけを「余裕があれば試す」に変更する。

3. **ライブデモ(講師手元、1〜2分)**
   スケジュールタスクを1つ設定する様子だけ見せる(例: 「毎週月曜に先週の完了タスク一覧をまとめる」)。深追いしない。

4. **宿題配布**(1分)
   `handouts/cowork-homework.md` を配布。内容: 「自分の定型業務を1つ選び、Claude Cowork で自動化を試す。次回セミナーで結果を共有する」

## 講師メモ
- Cowork のプラン・提供状況は変わりやすい。当日の朝に最新の提供条件(対応OS、対応プラン)を確認してから話す
- 宿題は強制ではなく「継続的に触ってもらうための仕掛け」という位置づけを明言する
